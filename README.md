# Hakureya

## Graph Interface 1.0
Полноэкранный SVG-граф: четыре цветных кластера, белое ядро, звёздное поле, рост и автоматическое отдаление камеры. Колесо — масштаб, перетаскивание — панорамирование. ЛКМ по аватару — чат, ПКМ — настройки.

Запуск Windows: Python 3.11+ и Node.js 22 для первой сборки. Запустите START.bat. При наличии dist Node и интернет для запуска не нужны. База SQLite — data/. Ключ Cloud.ru хранится только в оперативной памяти; платные запросы только после согласия в меню. Без ключа история сохраняется, генерация не имитируется.

Проверки: npm test; npm run build; python -m unittest discover -s tests -v. CI: Windows и Linux.

Ограничения: 115 демонстрационных узлов, не реальные записи памяти. Шрифт и оригинальный алгоритм не идентифицированы. Аватар — компактная версия исходного изображения. Пиксельное совпадение, 5000 узлов, динамический RAG и стриминг пока не реализованы или не проверены.
